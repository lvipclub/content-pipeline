## Post (merged from Dify's two concatenated drafts — known defect; one link, ~1,300 chars)

A BMS is only as intelligent as the data it receives. A poorly selected or drifting sensor doesn't just report bad data — it drives the whole system into inefficient operation.

Most control failures trace back to the sensor layer. LBNL fault studies find common faults, many sensor-related, can increase HVAC energy consumption by 15–30%. And the problem is often not drift: a temperature sensor reading 2 °C low from day one was never verified. ASHRAE Guideline 36-2021 is explicit — many performance issues trace to initial installation and calibration errors.

Sensor selection must start with application requirements, not catalogue specs. DCV-grade CO₂ needs NDIR technology and an accuracy class matched to the control loop; duct airflow sensors need straight runs away from elbows and dampers; placement per standard (ASHRAE 62.1 breathing-zone heights for CO₂) is part of the specification.

Before optimising control sequences, audit the sensor layer. Right-spec, place to standard, calibrate on a schedule — otherwise you are optimising noise.
